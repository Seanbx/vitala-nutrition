# 增肌食材推荐

## 概念介绍
增肌饮食的核心是提供充足的蛋白质和能量，支持肌肉蛋白质合成和恢复。选择合适的食材对于增肌效果至关重要。理想的增肌食材应该具有高蛋白、适量碳水化合物、适量健康脂肪的特点，同时易于消化吸收。

增肌期间，蛋白质的摄入时机和质量都很重要。训练后是肌肉蛋白质合成的高峰期，此时补充优质蛋白质效果最佳。同时，碳水化合物的摄入也很重要，它可以促进胰岛素分泌，帮助氨基酸进入肌肉细胞，促进肌肉生长。

## 具体内容
**优质蛋白质食材：**

1. **鸡胸肉**：蛋白质含量31克/100克，低脂肪，易于消化吸收，是增肌的首选食材。

2. **瘦牛肉**：蛋白质含量26克/100克，富含肌酸和铁，有助于肌肉生长和恢复。

3. **三文鱼**：蛋白质含量20克/100克，富含Omega-3脂肪酸，具有抗炎作用，促进恢复。

4. **鸡蛋**：蛋白质含量13克/100克，氨基酸组成完美，是"完全蛋白质"的代表。

5. **希腊酸奶**：蛋白质含量10克/100克，富含钙和益生菌，适合加餐或甜点。

**优质碳水化合物食材：**

1. **糙米**：碳水化合物含量23克/100克，低GI，持续供能。

2. **燕麦**：碳水化合物含量66克/100克，富含β-葡聚糖，增加饱腹感。

3. **红薯**：碳水化合物含量20克/100克，富含维生素A和纤维。

4. **香蕉**：碳水化合物含量23克/100克，富含钾，适合运动前后食用。

5. **全麦面包**：碳水化合物含量43克/100克，方便携带，适合加餐。

**健康脂肪食材：**

1. **牛油果**：脂肪含量15克/100克，富含单不饱和脂肪酸。

2. **坚果**：脂肪含量50-60克/100克，富含不饱和脂肪酸和蛋白质。

3. **橄榄油**：脂肪含量100克/100克，适合凉拌和低温烹饪。

**增肌饮食搭配建议：**
- 训练后：鸡胸肉 + 糙米 + 蔬菜
- 加餐：希腊酸奶 + 香蕉 + 坚果
- 正餐：瘦牛肉 + 红薯 + 西兰花

## 关键要点
- 鸡胸肉、瘦牛肉、鸡蛋是增肌期的核心蛋白质来源
- 糙米、燕麦、红薯是优质的复合碳水化合物来源
- 牛油果和坚果提供健康脂肪，维持激素水平
- 训练后30分钟内补充蛋白质和碳水化合物效果最佳
- 多样化食材选择，确保营养全面均衡
