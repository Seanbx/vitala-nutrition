# 安全与健康风险控制设计

## 一、医疗边界声明

### 1.1 系统定位

**本系统是饮食推荐助手，不是医疗诊断系统。**

- 提供饮食建议和营养参考
- 不能替代医生、营养师的专业诊疗
- 不能用于疾病诊断、治疗、预防
- 不能替代药物治疗

## 二、过敏风险校验机制

### 2.1 过敏原定义

**系统支持的过敏原类型：**
- 海鲜类：虾、蟹、贝类、鱼类
- 蛋奶类：鸡蛋、牛奶、乳制品
- 坚果类：花生、核桃、杏仁、腰果
- 豆类：大豆、豆腐、豆浆
- 麸质：小麦、大麦、燕麦
- 其他：芝麻、芹果、芥末

### 2.2 过敏校验流程

```
用户查询
    ↓
公共菜谱库检索（Top-20）
    ↓
过敏原校验
    ↓
├── 菜谱过敏原标签完整
│   └── 检查与用户过敏原是否冲突
│       ├── 无冲突 → 通过
│       └── 有冲突 → 过滤
│
└── 菜谱过敏原标签缺失
    └── 标记为"过敏原未知"，不推荐给有过敏史的用户
```

### 2.3 过敏原数据结构

```json
{
  "allergen_info": {
    "has_allergens": true,
    "allergens": ["shrimp", "crab"],
    "confidence": 0.95,
    "source": "recipe_metadata"
  }
}
```

### 2.4 过敏风险等级

| 等级 | 说明 | 处理方式 |
|------|------|----------|
| 高风险 | 菜谱明确含有用户过敏原 | 强制过滤，不推荐 |
| 中风险 | 菜谱过敏原信息缺失 | 标记警告，不推荐给高敏用户 |
| 低风险 | 菜谱不含用户过敏原 | 正常推荐 |

### 3.2 安全阈值校验

**最低热量标准：**
- 女性：不低于1200kcal/天
- 男性：不低于1500kcal/天
- 任何情况下：不低于基础代谢的80%

**校验逻辑：**
```python
def check_calorie_safety(calorie_target, gender, age, weight, height):
    # 计算基础代谢
    bmr = calculate_bmr(gender, age, weight, height)
    
    # 最低热量标准
    min_calories = 1200 if gender == "female" else 1500
    min_from_bmr = bmr * 0.8
    
    # 取较高值作为安全下限
    safe_minimum = max(min_calories, min_from_bmr)
    
    if calorie_target < safe_minimum:
        return {
            "safe": False,
            "message": f"每日热量不低于{safe_minimum}大卡，请调整目标",
            "suggested_calories": safe_minimum
        }
    
    return {"safe": True}
```

    def __init__(self):

        # 1. 检查危险饮食模式

                "safe": False,
                "type": "dangerous_pattern",

### 6.2 过敏校验器

```python
class AllergenValidator:
    def __init__(self):
        self.risk_levels = {
            "high": "菜谱含有你的过敏原，不推荐",
            "medium": "菜谱过敏原信息不完整，建议谨慎",
            "low": "菜谱不含已知过敏原"
        }
    
    def validate_recipe(self, recipe, user_allergens):
        """校验菜谱对用户是否安全"""
        recipe_allergens = recipe.get("allergens")
        
        # 菜谱过敏原信息缺失
        if recipe_allergens is None:
            return {
                "safe": False,
                "risk_level": "medium",
                "message": self.risk_levels["medium"]
            }
        
        # 检查是否有交集
        if set(recipe_allergens) & set(user_allergens):
            return {
                "safe": False,
                "risk_level": "high",
                "message": self.risk_levels["high"],
                "conflicting_allergens": list(set(recipe_allergens) & set(user_allergens))
            }
        
        return {
            "safe": True,
            "risk_level": "low",
            "message": self.risk_levels["low"]
        }
    
    def filter_recipes(self, recipes, user_allergens):
        """过滤不安全的菜谱"""
        safe_recipes = []
        for recipe in recipes:
            validation = self.validate_recipe(recipe, user_allergens)
            if validation["safe"]:
                recipe["allergen_check"] = validation
                safe_recipes.append(recipe)
        
        return safe_recipes
```
