## 十、个性化推荐逻辑

### 10.1 营养计算
```
1. 根据用户身体数据计算BMR
2. 根据活动水平计算TDEE
3. 根据健身目标调整热量
4. 计算三大营养素分配
5. 考虑特殊健康状况调整
```

### 10.2 菜谱推荐
```
1. 根据用户饮食模式筛选
2. 排除过敏原和不耐受食物
3. 根据口味偏好排序
4. 匹配当前热量和营养需求
5. 考虑烹饪能力和时间
6. 推荐多样化菜品
```

### 10.3 动态调整
```
1. 根据体重变化调整热量
2. 根据运动量调整营养
3. 根据反馈优化推荐
4. 考虑平台期调整策略
5. 定期评估目标进度
```
