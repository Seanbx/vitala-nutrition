# 动态个性化知识库系统设计

## 核心理念

**"越用越懂你"** - 通过每次对话不断充实用户画像，形成专属知识库

## 三、动态学习机制

### 3.1 信息采集方式

| 采集方式 | 说明 | 示例 |
|----------|------|------|
| **主动询问** | AI引导用户填写基础信息 | "请告诉我你的身高体重？" |
| **对话提取** | 从聊天中自动提取信息 | "我最近在减肥" → 更新目标为减脂 |
| **行为观察** | 从用户选择推断偏好 | 用户常选低卡菜品 → 偏好低卡 |
| **反馈学习** | 从评价中学习偏好 | "这个太辣了" → 降低辣度偏好 |

### 3.2 对话示例

```
用户：你好，我想减肥

AI：好的！我来帮你。首先需要了解一下你的情况：
    1. 你的性别是？
    2. 今年多大了？
    3. 身高体重是多少？
    4. 平时运动吗？

用户：女，25岁，160cm，58kg，偶尔运动

AI：[系统自动更新用户画像]
    ✓ 性别：女
    ✓ 年龄：25岁
    ✓ 身高：160cm
    ✓ 体重：58kg
    ✓ 目标：减脂
    ✓ 活动水平：轻度
    
    根据计算，你每天需要摄入约1400大卡。
    今天早餐想吃什么？

用户：有什么推荐的？

AI：[基于用户画像推荐]
    根据你的情况（减脂期、乳糖不耐受）：
    推荐：希腊酸奶碗（185kcal，18g蛋白）
    
用户：好的，就这个

AI：[记录饮食]
    ✓ 已记录：早餐 - 希腊酸奶碗 185kcal
    
    对了，你刚才说偶尔运动，一般是做什么运动？
    一周几次？

用户：一周2次瑜伽

AI：[更新运动习惯]
    ✓ 运动频率：有时（每周1-2次）
    ✓ 运动类型：瑜伽
    
    你的运动习惯不错！瑜伽对减脂塑形很有帮助。
    今天午餐想吃什么？
```

## 四、知识库更新机制

### 4.1 实时更新

```python
# 每次对话后触发更新
def after_chat_update(user_id, chat_content):
    # 1. 提取新信息
    new_info = extract_info_from_chat(chat_content)
    
    # 2. 更新用户画像
    update_user_profile(user_id, new_info)
    
    # 3. 记录行为
    record_behavior(user_id, chat_content)
    
    # 4. 学习偏好
    learn_preferences(user_id, chat_content)
    
    # 5. 更新推荐
    update_recommendations(user_id)
```

### 4.2 信息提取规则

| 用户输入 | 提取信息 | 更新字段 |
|----------|----------|----------|
| "我最近在减肥" | 目标=减脂 | fitness_goal |
| "我不吃辣" | 辣度偏好=不辣 | flavor_preferences.spicy_level |
| "我对海鲜过敏" | 过敏原=海鲜 | food_allergies |
| "我每天喝咖啡" | 咖啡频率=每天 | beverage_habits.coffee.frequency |
| "最近睡得不好" | 睡眠质量=差 | sleep_schedule.sleep_quality |
| "工作压力很大" | 压力=高 | stress_level |

## 五、个性化推荐进化

### 5.1 推荐算法演进

```
初始状态：基于基础画像推荐
    ↓
第一次交互：用户说"不喜欢吃鱼"
    ↓
更新：排除鱼类菜品
    ↓
第二次交互：用户选择"低卡菜谱"
    ↓
学习：用户偏好低卡
    ↓
持续进化：推荐越来越精准
```

### 5.2 推荐示例

**初始推荐（仅知道基础信息）：**
```
推荐：黑椒牛肉糙米饭（385kcal）
理由：高蛋白，适合减脂
```

**进化后推荐（了解用户偏好后）：**
```
推荐：柠檬鸡胸肉（185kcal）
理由：
1. 低卡（符合减脂需求）
2. 不含海鲜（排除过敏原）
3. 烹饪简单（符合忙碌上班族）
4. 你喜欢鸡肉（历史选择记录）
```
